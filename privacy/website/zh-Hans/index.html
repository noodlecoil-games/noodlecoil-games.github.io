联系方式

本网站以 Noodlecoil Games 品牌发布。如有隐私问题，请发送邮件至 noodlecoilgames@gmail.com。

网站与托管

本站未主动加入分析工具、广告脚本、追踪像素、邮件订阅表单或追踪 Cookie。网站由 GitHub Pages 托管，GitHub 可能为运营及保障服务安全而处理 IP 地址和技术请求日志。

电子邮件

如果您联系我们，我们会收到您的邮箱地址、邮件内容以及您提供的附件，并用于回复。请勿发送不必要的敏感信息。

共享和保留

我们不会出售通过本网站收集的访客数据。GitHub 提供网站托管，邮件服务提供商处理通信。邮件将在处理请求及履行适用义务所需的合理时间内保存。

您的权利与外部链接

在适用情况下，您可通过邮件请求访问、更正或删除信息。外部网站适用其自身政策。有关 GitHub Pages 的处理情况，请参阅 GitHub 隐私声明。

变更

若网站新增表单、分析功能、广告脚本或其他数据处理功能，我们将更新本说明。
