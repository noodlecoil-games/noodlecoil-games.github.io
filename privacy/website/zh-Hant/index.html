聯絡方法

本網站以 Noodlecoil Games 品牌發佈。如有私隱疑問，請電郵至 noodlecoilgames@gmail.com。

網站及託管

本站沒有主動加入分析工具、廣告程式、追蹤像素、電郵訂閱表格或追蹤 Cookie。網站由 GitHub Pages 託管；GitHub 可能為營運及保障服務安全而處理 IP 位址及技術請求記錄。

電子郵件

如你聯絡我們，我們會收到你的電郵地址、郵件內容及你提供的附件，並用作回覆。請勿發送不必要的敏感資料。

分享及保留

我們不會出售透過本網站收集的訪客資料。GitHub 提供網站託管，電郵服務供應商處理通訊。郵件會在處理查詢及履行適用義務所需的合理時間內保留。

你的權利及外部連結

在適用情況下，你可電郵要求查閱、更正或刪除資料。外部網站適用其本身的政策。有關 GitHub Pages 的處理方式，請參閱 GitHub 私隱聲明。

更改

如網站新增表格、分析功能、廣告程式或其他資料處理功能，我們會更新本聲明。
